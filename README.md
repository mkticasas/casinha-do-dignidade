# Casinha do Dignidade

Site da casa de festa com orçamento automático no WhatsApp. Atendimento iMarcas.

| Arquivo | O que é |
|---|---|
| `index.html` | Site (landing page + orçamento) |
| `painel-casinha.html` | Painel interno de preços das carnes e açougue parceiro (sem link no site) |
| `logo-casinha.png` / `logo-casinha-alta.png` | Logo com fundo transparente |

Preços das carnes: enquanto `SUPABASE_URL` estiver vazio no `index.html` e no `painel-casinha.html`, o site usa os preços fixos e o painel roda em modo demonstração (salva só no navegador).
